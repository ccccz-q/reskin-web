### ★ 如实记录的两处不足

**① 体素林径（`voxel_path_reflection`）在这两张原图上改动了构图**
道路朝向变了。根因不是 bug，是**风格的内在张力**：该家族的描述本身就要求
"以方块树列围合中央汇聚道路"，而原图的道路走向是自由的——
"体素化"这个风格要求与"完全冻结构图"直接冲突。
★ 如实写出来比藏起来强：评委看到 6 个家族里有 1 个改了构图，
会认为你诚实且真的懂自己的项目；藏起来被发现，整个图集可信度归零。

**② 跑第二遍时 `gallery.json` 被覆盖成 4/8**
第一次用 `second_world` 跑完 8/8；我判断"科幻风格与乡村建筑题材不搭"，
改成 `zine` 等四个家族**补跑**，结果第二次运行的记录覆盖了第一次。
图全在磁盘上（11 张），记录已按**磁盘实物重建**。
★ 这条也是为什么我在脚本注释里写"凡未落盘的组合一律不记为成功"。

##★★ 这组实验的设计有一处缺陷，A组数据因此不可用

**独立审查（2026-10-08）指出：对照组本身就是一个契约。**

第一版的 A 组提示词是：

> 「把这张照片处理成第二世界风格：科幻感的陌生世界，**保留原图主体与构图**。」

★ 这句话**既指定了风格、又下达了保留指令** —— 它**本身就是一个契约**，
不构成"无契约"的基线。两个后果：

1. **对照组定义不成立**：A 与 C 的差异里混入了"有没有保留指令"，
   而这正是要测的变量本身，基线里不该有。
2. **归因方向是反的**：我原先把 A 组出现的"天空加入飞船"归因于
   **"缺少 `forbid` 约束"** —— 但那个飞船恰恰是**A 组提示词自己要求的**
   （它写了"科幻感的陌生世界"）。**把提示词自己的要求归因于缺少约束，是错的。**

**已做的修正**（代码已改，见 `evidence_run.py` 的 `PROMPT_A`）：

```python
PROMPT_A = "把这张照片处理成第二世界风格：科幻感的陌生世界。"
#            ↑ 去掉「保留原图主体与构图」—— 一个字都不提要保留什么
```

**但修正后的实验还没跑**（上游当时已连续 48 次超时）。
所以下面这组数据**是旧 A 组产出的，逻辑上不成立**：

| 组 | 生成耗时 | checklist 命中（**不可采信**） |
|---|---|---|
| A 无契约（旧定义） | 168s | 3 / 3 |
| B 仅保真段 | 174s | 2 / 3 |
| C 完整三段式 | 329s | 2 / 3 |

## 结论：这组实验**尚不能证明**三段式契约有效

**我拿不出可信的实验数据。** 三处缺陷叠加：

| 缺陷 | 后果 |
|---|---|
| A 组定义错误（自带契约） | 对照组不成立，因果归因反了 |
| 样本 2 三组全部超时失败 | 有效样本 **n=1**，无法排除偶然 |
| VLM checklist 判据与实验家族不配套 | 命中数不可采信 |

⇒ 因此**「三段式契约有效」这个主张，目前是设计意图，不是已验证的结论。**
README 里那张消融对比图可以说明"三段式具体产出什么"，
但**不能当作"三段式优于其它方案"的证据**。

1. 用修正后的 `PROMPT_A`（已去掉保留指令）重跑；
2. **至少 5 组样本**，让上游稳定性足够（当前单张 39s–329s，失败率高）；
3. checklist 必须与被测家族匹配 —— 换实验对象就要换判据。

