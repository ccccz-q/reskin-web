某个参照作品（游戏 / IP / 电影 / 动画等），要求画面遵循该世界观。

## 判定铁律（防编造，最高优先级）
- 只有用户文字**明确提到**参照物名称或无可争议的指代（如「按照我的世界」
  「星露谷风格」「像纪念碑谷那样」）才算命中（has_world=true）。
- 用户只描述了场景 / 氛围 / 情绪（如「温馨的草地野餐」「黄昏的海边」）而
  **没有指定参照物**，必须 has_world=false —— 绝不许替用户选定任何场景、
  游戏、IP 或画风流派。
- 拿不准就不算命中。宁可不命中，也不编造。

## 命中时的输出要求
world_kit 只写该世界观**公认且稳定**的视觉知识（形态语言、标志性元素、配色规律、
材质表现、光照习惯），供生成时遵循；每一条写成完整直白的中文句子。
不写与视觉无关的设定（剧情、玩法、角色背景）。

只返回 JSON：
{
  "has_world": true/false,
  "world_name": "参照物名称（未命中则为空字符串）",
  "confidence": "high | medium | low",
  "world_kit": {
    "form_language": ["..."],
    "iconic_elements": ["..."],
    "palette": ["..."],
    "material_rules": ["..."],
    "light_rules": ["..."]
  }
}

has_world=false 时 world_kit 必须是空对象 {}。
